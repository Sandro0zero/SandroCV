# CV Online - Sandro Xeva

## Cara menjalankan
1. Buka `index.html` di browser.
2. Ganti email, LinkedIn, GitHub, dan WhatsApp pada bagian Contact.
3. Jika sudah punya CV PDF, beri nama `cv.pdf` lalu taruh di folder yang sama.
4. Upload seluruh folder ke GitHub Pages, Netlify, atau Vercel untuk mendapatkan link online.

## Catatan
Nama dan informasi proyek sudah diisi berdasarkan data yang tersedia. Kontak masih berupa placeholder dan perlu diganti.
